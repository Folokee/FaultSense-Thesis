\section{Fault Diagnosis}\label{sec:fault-diagnosis}

\subsection{Introduction}
After an anomalous state is detected, the next step in an FDD workflow is to identify the most likely fault type. In this project, diagnosis is formulated as a supervised multi-class classification task over engineered features extracted from PV system measurements. Unlike the anomaly detection stage, labeled fault categories are available for training; the objective is to output a discrete fault class among $C=4$ predefined types.


\subsection{Model Lineup}

\subsubsection{LightGBM Classifier}

LightGBM builds an additive ensemble of decision trees by gradient boosting: starting from a constant prediction, each successive tree $f_m$ is fitted to the negative gradient of the loss with respect to the current ensemble output - the pseudo-residuals. For multi-class classification with $C$ classes, $C$ parallel score models are maintained, one per class, updated simultaneously at every boosting round. Two key algorithmic innovations reduce cost: \emph{Gradient-based One-Side Sampling} (GOSS), which retains all samples with large gradients and randomly subsamples those with small gradients, preserving the informative part of the gradient signal; and \emph{Exclusive Feature Bundling} (EFB), which detects and merges mutually exclusive sparse features, reducing the effective feature count without information loss. Splits are found over histograms of binned feature values rather than by exhaustive exact search, yielding sub-linear complexity per tree. Class imbalance is handled through balanced class weights.

\paragraph{Training objective.}
The objective is the multiclass cross-entropy loss over $N$ samples and $C$ classes:
\begin{equation}
    \mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{c=1}^{C} y_{ic}\,\log\hat{p}_{ic},
\end{equation}
where $y_{ic}\in\{0,1\}$ is the one-hot class indicator and $\hat{p}_{ic} = \text{softmax}(F_c(x_i))$ is the predicted probability, with $F_c(x) = \sum_{m=1}^{M} f_{m,c}(x)$ the accumulated score for class $c$ over $M$ boosting rounds.

\paragraph{Prediction.}
The final class assignment is:
\begin{equation}
    \hat{y} = \arg\max_{c}\; F_c(x).
\end{equation}

\subsubsection{CatBoost Classifier}

CatBoost is a gradient boosted tree library distinguished by two structural choices that jointly address the two main sources of overfitting in standard gradient boosting.

First, it grows \emph{oblivious} (symmetric) trees in which the same splitting condition is applied to all nodes at a given depth level, producing a balanced binary tree of depth $d$ with exactly $2^d$ leaves. Because the leaf index of any sample reduces to a single table lookup (each level contributes one bit), inference is cache-efficient and fast. The symmetric structure also acts as an implicit regulariser: every split must justify itself across the entire width of the tree rather than locally at one node.

Second, it uses \emph{ordered boosting}: standard gradient boosting estimates pseudo-residuals for sample $i$ from a model that was fitted on data including $i$ itself, introducing a subtle overfitting bias. CatBoost eliminates this by maintaining $N$ separate model versions, one per training sample, where the model used to compute the gradient of sample $i$ was fitted only on samples preceding $i$ in a random permutation. This yields unbiased gradient estimates without holding out a separate validation set. Class imbalance is handled through native balanced class weighting.

\paragraph{Training objective.}
CatBoost minimises the multiclass cross-entropy loss:
\begin{equation}
    \mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{c=1}^{C} y_{ic}\,\log\hat{p}_{ic},
\end{equation}
where class scores are accumulated over oblivious trees and converted to probabilities via softmax.

\paragraph{Prediction.}
The predicted class is $\hat{y} = \arg\max_{c}\; F_c(x)$, where $F_c(x) = \sum_{m=1}^{M} f_{m,c}(x)$ sums the leaf values of all oblivious trees for class $c$.

\subsubsection{ExtraTrees Classifier}

ExtraTrees (Extremely Randomised Trees) is a tree ensemble that pushes the randomisation of Random Forest one step further. In a standard Random Forest, each node selects the best split threshold by optimising an impurity criterion over the actual observed data values for each candidate feature. ExtraTrees also randomises the threshold: for each of the $k$ candidate features, a split threshold is drawn \emph{uniformly at random} from the feature's observed range, and the best among all $k$ (feature, threshold) pairs is retained. This double randomisation (both over features and over thresholds) further decouples each tree from the specific sample values in the training set, reducing variance more aggressively than a standard Random Forest at the cost of a small bias increase. The ensemble is built on the full training set per tree; bootstrap sampling is enabled in the selected configuration (Table~\ref{tab:et-hpo}). Class imbalance is handled through balanced class weights.

\paragraph{Split criterion.}
Trees are grown by maximising the information gain at each node. For a node with class distribution $\{p_c\}_{c=1}^{C}$, the entropy impurity is:
\begin{equation}
    H = -\sum_{c=1}^{C} p_c \log p_c.
\end{equation}
The candidate split that maximises $\Delta H = H_{\text{parent}} - \bigl(w_L H_L + w_R H_R\bigr)$, with $w_L, w_R$ the weighted child fractions, is selected from the $k$ randomly generated (feature, threshold) pairs. The \texttt{criterion=entropy} configuration corresponds to this information-gain criterion.

\paragraph{Prediction.}
Each tree assigns class probabilities $\hat{p}_c^{(t)}(x)$ as the empirical class fraction in the leaf reached by $x$. The ensemble averages over all $T$ trees:
\begin{equation}
    \hat{p}_c(x) = \frac{1}{T}\sum_{t=1}^{T}\hat{p}_c^{(t)}(x), \qquad \hat{y} = \arg\max_{c}\;\hat{p}_c(x).
\end{equation}
These probability estimates are subsequently passed through Platt scaling (Section~\ref{sec:diag-winner}) before deployment.

\paragraph{Why ExtraTrees wins.}
Figure~\ref{fig:cls-macro} confirms that ExtraTrees scores the highest macro F1 with the tightest spread across folds. Its extra randomisation (drawing split thresholds at random rather than searching for the best one) acts as a built-in regulariser. This is especially useful here because the minority fault classes have very few episodes: boosting methods such as LightGBM and CatBoost tend to over-focus on the majority class under these conditions, while ExtraTrees' independent trees maintain a more balanced decision boundary.

\paragraph{Where all models agree.}
Open-Circuit (cls~3) is classified at near-perfect F1 by all three models across all folds. The fault produces a clear electrical signature (the string current drops to zero while irradiance stays normal) leaving no ambiguity in the feature space. Shadowing (cls~4) is also reliably identified, partly because it is by far the most frequent class in the dataset.

\paragraph{The hardest class: Degradation (cls~2).}
Figure~\ref{fig:cls-perclass} reveals that Degradation is the most difficult fault in both Task~A and Task~B. In the classification task, its low-severity samples look similar to Short-Circuit faults, which explains the relatively low precision (0.797): some Short-Circuit samples are misclassified as Degradation. The per-class PR-AUC of 0.970 shows that the ranking quality is still good, but the decision boundary struggles with the most ambiguous cases.

\paragraph{Feature engineering validates itself.}
Figure~\ref{fig:et-feat-importance} shows that the two most important features are both physics-derived: \texttt{voltage\_imbalance} alone accounts for 41\% of the total importance, and \texttt{pdc\_temp\_corrected} contributes a further 16\%. Together they represent over half the model's decision weight. \texttt{power\_imbalance} and \texttt{current\_imbalance} also appear in the top ten. These are quantities a raw sensor reading cannot provide directly - they are computed from ratios and corrections across multiple measurements and encode how each fault type disturbs the panel's normal operating relationships. Raw electrical signals (\texttt{vdc2}, \texttt{idc1}, \texttt{idc2}, \texttt{irr}) fill the remaining positions with much smaller contributions. This result directly validates the \texttt{plus\_physics} feature profile: the model relies primarily on the engineered features, not the raw inputs. This stands in deliberate contrast to Task~A, where the normalizing flow learns its own internal representations and the same hand-crafted features proved redundant.

\subsection{Deployed Model}\label{sec:diag-winner}

The deployed classifier is ExtraTrees on the \texttt{plus\_physics} feature profile. As described in Section~\ref{sec:prob-calibration}, the raw class scores are post-hoc recalibrated on the validation partition using Platt scaling before deployment, so that the confidence values presented to the operator reflect true empirical frequencies.

Table~\ref{tab:et-calibration} reports the calibration quality on the held-out test set. Log-loss of 0.059 and a Brier score of 0.008 confirm that the probability outputs are well-aligned with empirical frequencies. The ECE of 0.019 indicates a small residual miscalibration averaged across confidence bins; the MCE of 0.754 captures a tail-bin effect in the high-confidence region. The calibrated probabilities are surfaced alongside the diagnostic label in the monitoring interface (Chapter~\ref{ch:deployment}).
