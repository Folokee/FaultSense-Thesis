\section{Anomaly Detection}\label{sec:anomaly-detection}

\subsection{Introduction}
Anomaly detection is the process of distinguishing between normal and anomalous states in a PV system. This chapter introduces the problem, presents the explored models, evaluates them with robust cross-validation estimates, and concludes with an analysis of the winning design.

\subsection{Task Formulation and Methodology}
The anomaly detection task is formulated as a semi-supervised learning problem: models are trained exclusively on normal-behavior data and evaluated on held-out fault and normal samples. The shared framework across all detectors is:
\begin{itemize}
    \item Train on normal-only segments to learn a compact model of nominal PV operation.
    \item Derive a scoring function $s(x)$ where higher values indicate higher anomaly likelihood.
    \item Calibrate a decision threshold $\tau$ from held-out normal validation scores; flag samples with $s(x) \geq \tau$ as anomalous.
\end{itemize}

\subsection{Shared Experimental Infrastructure}\label{sec:ad-shared-infra}

\paragraph{Splits and episode stratification.}
All detectors use the splitting protocol of Section~\ref{sec:implementation-splitting}. The training partition contains only normal segments; all fault segments are held out. To obtain robust uncertainty estimates, hyperparameters are optimised \emph{once} on the original temporal holdout, then the winning configuration is retrained across $K=5$ episode-stratified folds (val+test pool partitioned per class). Train data is held fixed across folds; only val/test rotate. Every metric is reported as mean~$\pm$~std over the five folds.

\paragraph{Deep-learning windowing.}
DL detectors operate on fixed-length windows of size $W$ with stride $s$. A shared \texttt{TimeSeriesDataset} returns tensors of shape $[B, W, F]$ and respects segment boundaries: windows never cross continuity gaps, preventing implicit leakage.

\paragraph{Threshold calibration.}
Thresholds are calibrated exclusively on held-out normal validation scores using a Peaks-Over-Threshold (POT) Generalised Pareto Distribution (GPD) fit with quantile $q=0.90$, targeting a false-alarm rate of 5\% on normal data. When the tail fit is numerically unstable a quantile fallback (95th percentile of normal scores) is used.

\paragraph{Evaluation metric.}
Because the normal class dominates recordings ($\sim$97\%), binary PR-AUC is a misleading headline metric: a model that globally confuses fault classes can still report a high binary score. The primary metric is therefore \textbf{macro per-class PR-AUC}: for each fault class $c$, a one-vs-normal subset is formed by keeping only samples of class $c$ and the normal class; the area under the precision-recall curve (PR-AUC) is computed on that subset, giving a score that reflects how well the model separates that specific fault from normal operation. The macro per-class PR-AUC is the unweighted average of these four values. The worst-class PR-AUC (the minimum of the four) is also reported as a pessimistic safety bound. All three are threshold-free and computed at both the \emph{sample/window} level and the \emph{episode} level. The episode-level variant aggregates the per-sample scores within each fault episode to a single episode score (using the 95th percentile of scores within the episode), then computes PR-AUC over episode-level predictions; this is a more operationally relevant view because a detector only needs to fire once per fault event.

\paragraph{Leakage validation.}
After each fold, an automated leakage audit runs a \emph{label-shuffle test}: the test labels are randomly permuted and the PR-AUC is recomputed; if the model's performance collapses to approximately the positive class prevalence, this confirms that performance depends on true label structure and not on data-ordering artefacts. A fold is marked clean (\texttt{leakage\_is\_clean}~=~1) when this test passes.

\subsection{Model Lineup}

\subsubsection{Bayesian Online Change-Point Detection (BOCD)}

BOCD tracks a run-length distribution, i.e. the probability that the current time step is $r$ steps into the present stationary segment. When the posterior concentrates near zero, a change point is likely.

Each feature is modelled independently with a Normal-Inverse-Gamma (NIG) conjugate prior, which places a prior over both the mean and variance of a Gaussian and allows exact Bayesian updates. The joint predictive density is the product of four univariate Student-$t$ predictives. A geometric hazard parameter $\lambda$ sets the expected run length between change points ($h = 1/\lambda$).

\paragraph{Scoring function.}
\begin{equation}
    s_t = -\log\!\left(\sum_{r=0}^{R_{\max}} R_t(r)\, p(x_t \mid r)\right),
\end{equation}
where $R_t(r)$ is the run-length posterior, $p(x_t \mid r)$ the Student-$t$ predictive density under run length $r$, and $R_{\max}=200$ a truncation limit. The run-length distribution is reset at each segment boundary to prevent state from a previous episode affecting the next.

\subsubsection{Isolation Forest}

Isolation Forest builds an ensemble of random partitioning trees. Anomalous points require fewer splits to be isolated and therefore have shorter average path lengths from the root.

\paragraph{Scoring function.}
Each isolation tree is built by recursively selecting a random feature and a random split threshold until a point is isolated in its own leaf. The \emph{path length} $h(x)$ is the number of splits needed to isolate sample $x$ in one tree. Anomalous points, being rare and far from the bulk of the data, are separated in very few splits; normal points, densely packed with similar neighbours, require many more. The raw anomaly score in the original formulation~\citep{liu2008isolation} is:
\begin{equation}
    s(x,\psi) = 2^{-\,\mathbb{E}[h(x)]\,/\,c(\psi)},
\end{equation}
where $\mathbb{E}[h(x)]$ is the average path length over all trees and $c(\psi) = 2H(\psi-1) - 2(\psi-1)/\psi$ is a normalisation constant equal to the expected path length of an unsuccessful binary search over $\psi$ samples ($H$ denotes the harmonic number). This normalisation makes the score comparable across different subsample sizes. A score near 1 signals an anomaly (short average path); a score near 0 signals a normal point.

Sklearn's \texttt{score\_samples} returns the negative normalised average path length directly, so lower (more negative) values indicate anomalies. Negating aligns with the project-wide convention that higher values indicate greater anomaly likelihood:
\begin{equation}
    s(x) = -\texttt{score\_samples}(x).
\end{equation}

\texttt{n\_estimators} controls the number of trees; \texttt{max\_samples} the number of points used to build each tree; \texttt{max\_features} the fraction of features sampled per split. Table~\ref{tab:iforest-hpo} summarises the search and winning configuration.

\subsubsection{One-Class Support Vector Machine (OC-SVM)}

OC-SVM maps the training data into a high-dimensional feature space via a kernel function $k(x, x')$ and finds the tightest hyperplane that encloses the normal training data with a controlled fraction of outliers. The decision function $f_{\text{OCSVM}}(x)$ is positive for points inside the boundary (normal) and negative for points outside (anomalous). Two kernel families were explored separately: the Radial Basis Function (RBF) kernel $k(x,x') = \exp(-\gamma\|x-x'\|^2)$ and a cubic polynomial kernel.

\paragraph{Training subsample.}
The full normal training set contains 183\,801 samples. Because fitting a kernel SVM scales cubically with the number of support points, a group-stratified temporal subsample of 40\,000 samples is drawn before fitting, preserving episode diversity. Evaluation is performed on the complete val and test partitions.

\paragraph{Scoring function.}
\begin{equation}
    s(x) = -f_{\text{OCSVM}}(x),
\end{equation}
so that points outside the normal boundary score high.

\paragraph{Hyperparameter search space.}
\texttt{nu} sets an upper bound on the fraction of training points allowed outside the boundary; \texttt{gamma} is the inverse width of the Gaussian kernel. Table~\ref{tab:ocsvm-hpo} reports the search space and winning values.

\subsubsection{Mamba Adaptive Anomaly Transformer (MAAT)}

The model implemented here is a variant of the architecture proposed by \citet{sellam2025maat}, who introduced the Mamba Adaptive Anomaly Transformer combining sparse anomaly attention with a Mamba selective state-space model and association-discrepancy-based scoring. We adopt the core ideas from that work — the two-component attention mechanism (series and prior associations), the minimax training objective, and the association-discrepancy anomaly score — and apply targeted modifications to the integration structure and input embedding to better suit the multivariate PV time-series setting. The key differences from the original are:
\begin{itemize}
    \item \textbf{Embedding}: a \texttt{DataEmbedding} block (linear token projection + sinusoidal positional encoding + dropout) replaces the original embedding, making temporal position explicit from the first layer.
    \item \textbf{Parallel branch structure}: in the original MAAT, the Mamba-SSM is integrated into the reconstruction module and combined with the attention output via a skip connection and gated attention. In our variant, the Mamba branch runs \emph{in parallel} with the anomaly-attention branch at every encoder layer, so both operate on the same encoder input rather than sequentially.
    \item \textbf{Gating}: the skip-connection + gated-attention fusion of the original is replaced by a learned sigmoid gate applied to the concatenated branch outputs, allowing per-position, per-channel selection between the two temporal modelling strategies.
\end{itemize}
These modifications are surgical: the association-discrepancy semantics and the minimax training objective are preserved unchanged from \citet{sellam2025maat}; only the structural wiring is adapted.

\paragraph{Architecture.}
The overall structure is illustrated in Figure~\ref{fig:maat_architecture}. The model receives an input window $x \in \mathbb{R}^{B \times W \times F}$ and projects it through the \texttt{DataEmbedding} module. An $L$-layer encoder then processes the representation; each layer contains two parallel branches:
\begin{itemize}
    \item \textbf{Anomaly-attention branch}: computes a data-driven \emph{series association} $S$ via block-local sparse self-attention and a Gaussian-kernel \emph{prior association} $P$.
    \item \textbf{Mamba branch}: a selective state-space model (SSM) providing linear-complexity long-range sequence mixing.
\end{itemize}
The outputs $H_{\text{mamba}}$ and $H_{\text{attn}}$ are fused by a learned sigmoid gate:
\begin{equation}
    G = \sigma\!\left(W_g[H_{\text{mamba}} \| H_{\text{attn}}]\right), \qquad
    H_{\text{fused}} = G \odot H_{\text{mamba}} + (1-G) \odot H_{\text{attn}},
\end{equation}
where $[\cdot \| \cdot]$ denotes concatenation, $\odot$ element-wise multiplication, and $W_g$ a learned projection. A gate near 1 selects Mamba; near 0 selects attention. The fused representation passes through residual connections, Layer Normalisation, and a position-wise feed-forward network before the next layer.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{figures/detection/maat_architecture.png}
    \caption{MAAT architecture.}
    \label{fig:maat_architecture}
\end{figure}

\paragraph{Training objective.}
MAAT is trained with a minimax objective that combines reconstruction error with an association-discrepancy term. The Kullback–Leibler (KL) divergence $\mathrm{KL}(A \| B)$ measures how much distribution $A$ differs from $B$: a large value means the two distributions are very different. The objective is:
\begin{equation}
    \mathcal{L} = 2\mathcal{L}_{\text{rec}} + k\bigl[\mathrm{KL}(P \| S) - \mathrm{KL}(S \| P)\bigr],
\end{equation}
where $\mathcal{L}_{\text{rec}}$ is the per-window mean squared reconstruction error (how accurately the model reconstructs the input), $k$ controls the relative weight of the association term, and the two KL terms form a minimax objective: the prior association $P$ is pushed towards the series association $S$ while $S$ is simultaneously pushed away from $P$. On normal data this creates a characteristic divergence pattern; faults disrupt this pattern, making them detectable.

\paragraph{Scoring function.}
At inference time, the anomaly score for each time step $t$ combines reconstruction error with how much the temporal association pattern has deviated from the learned normal pattern. Let $\hat{x}_t$ be the model's reconstruction of input $x_t$. The association discrepancy at step $t$ is:
\begin{equation}
    D_t = \mathrm{KL}(S \| P) + \mathrm{KL}(P \| S).
\end{equation}
Steps with high discrepancy (unusual temporal patterns) receive higher weight. The weights are computed via a temperature-scaled softmax (which converts a vector of values into a probability distribution, amplified by temperature $T$):
\begin{equation}
    w_t = \mathrm{Softmax}(-T \cdot D_t),
\end{equation}
and the final per-step anomaly score is the discrepancy-weighted reconstruction error:
\begin{equation}
    A_t = w_t \cdot \|x_t - \hat{x}_t\|^2.
\end{equation}
The window-level score is the maximum of $A_t$ over all time steps in the window: a single highly anomalous time step is sufficient to flag the window.

\subsubsection{GTBAD: Gated Transformer-BiLSTM Anomaly Detector}\label{sec:ad-gtbad}

GTBAD is a reconstruction-based deep anomaly detector that combines a Transformer encoder with a bidirectional LSTM (BiLSTM) decoder. An input projection maps each time step to $d_{\text{model}}=64$; sinusoidal positional encodings are added; a 3-layer Transformer encoder with 2 attention heads captures temporal dependencies; a single-layer BiLSTM with hidden size 32 decodes the representation; and a linear projection reconstructs the original input. \subsubsection{Physics-Conditioned Normalizing Flow (PC-Flow)}\label{sec:ad-pcflow}

\paragraph{Idea.}
PC-Flow is a physics-conditioned normalizing flow: a family of generative models that combines the strengths of autoregressive models (tractable likelihoods) and variational autoencoders (representation learning)~\citep{rezende2015variational}. Unlike both, a normalizing flow $f_\theta : \mathbb{R}^n \to \mathbb{R}^n$ is \emph{deterministic and invertible}: given an input $x$ it produces a latent code $z = f_\theta^{-1}(x)$, and this transformation can be perfectly reversed. Because the transformation is invertible, the exact density of any input $x$ can be computed from the density of its latent code $z$ using the change-of-variables formula:
\begin{equation}
    \log p(x;\theta) = \underbrace{\log p_Z(f_\theta^{-1}(x))}_{\text{log-density of the latent code}} + \underbrace{\log\left|\det\!\left(\frac{\partial f_\theta^{-1}(x)}{\partial x}\right)\right|}_{\text{log volume change of the transformation}},
\end{equation}
where $p_Z$ is a simple base distribution (here a standard Gaussian) whose density is easy to evaluate, and the second term (the log absolute determinant of the Jacobian matrix of partial derivatives) corrects for how the transformation stretches or compresses volume in different regions. This means a normalizing flow \textbf{simultaneously learns a latent representation and yields a tractable, exact likelihood}, combining the best of both worlds: the model learns its own compact internal representation of normal PV operation without requiring manually engineered features beyond the raw signals.

\paragraph{Architecture.}
The flow consists of $L$ affine coupling layers~\citep{dinh2017realnvp}. Each layer splits the input, applies a scale-and-shift network conditioned on the first partition, and uses the inverse for tractable likelihood. The physics conditioning enters through an irradiance and temperature context vector appended to the coupling network inputs, allowing the model to factor out the operating-point effect on the measured signals.

\paragraph{Training objective.}
The model is trained by maximising the average negative log-likelihood (NLL) on normal training windows:
\begin{equation}
    \mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N} \log p(x_i;\theta).
\end{equation}

\paragraph{Scoring function.}
The anomaly score is the negative log-likelihood: $s(x) = -\log p(x;\theta)$. Under a well-trained flow, normal samples lie in the high-probability region and score low; anomalous samples deviate from the learnt manifold and score high.

\subsection{PC-Flow Design Ablations}\label{sec:ad-ablations}

Having established PC-Flow as the winner, this section analyses the design choices that lead to the selected configuration: the feature profile, the physics conditioning, and the scoring function.

\subsubsection{Profile Ablation: Why Raw Features Win}\label{sec:abl-profile}

Three feature profiles were evaluated under identical normalizing-flow architecture and HPO (Table~\ref{tab:pcflow-profile-abl}):

\begin{table}[H]
\centering
\caption{PC-Flow profile ablation.\label{tab:pcflow-profile-abl}}
\begin{tabular}{lccccc}
\toprule
\textbf{Profile} & \textbf{Modelled feat.} & \textbf{Context feat.} & \textbf{Macro PC PR-AUC} & \textbf{Worst} & \textbf{Params} \\
\midrule
\textbf{baseline\_raw}  & 7   & 2 & \textbf{0.990~$\pm$~0.005} & \textbf{0.962} & 20\,124 \\
plus\_physics   & 15  & 2 & 0.985~$\pm$~0.012 & 0.954 & 9\,418 \\
plus\_rolling   & 153 & 2 & 0.955~$\pm$~0.024 & 0.868 & 57\,546 \\
\bottomrule
\end{tabular}
\end{table}

Macro per-class PR-AUC degrades monotonically as the number of modelled features grows from 7 to 153. This is a hallmark of the \textbf{curse of dimensionality in density estimation}: the normalizing flow must model an increasingly high-dimensional normal distribution, making it harder to assign precise likelihoods to any given region. Importantly, a normalizing flow performs its \emph{own feature learning} as part of the bijective mapping; additional hand-engineered features are therefore redundant and ultimately harmful. The model extracts a latent representation that is jointly optimal for both likelihood estimation and anomaly scoring, without requiring explicit signal processing beyond the raw measurements. This result stands in deliberate contrast to the Task~B findings (Section~\ref{sec:fault-diagnosis}), where tree ensembles that \emph{cannot} learn representations benefit substantially from the same hand-crafted features.

\textbf{Deployed profile: baseline\_raw} (7 raw electrical + meteorological features). This also yields the lightest deployment footprint: 20\,124 parameters vs 57\,546 for the rolling profile.

Without conditioning, the same flow must capture the full marginal across all irradiance and temperature regimes, leading to a looser boundary and higher fold-to-fold instability.

\subsubsection{Scoring Ablation: Affine NLL vs Spline Typicality}\label{sec:abl-scoring}

Table~\ref{tab:pcflow-score-abl} compares the affine NLL and spline-typicality scoring variants.
\begin{table}[H]
\centering
\caption{PC-Flow scoring ablation.\label{tab:pcflow-score-abl}}
\begin{tabular}{lcccc}
\toprule
\textbf{Variant} & \textbf{Coupling} & \textbf{Scoring} & \textbf{Macro PC PR-AUC} & \textbf{Binary PR-AUC} \\
\midrule
\textbf{Affine NLL} (deployed) & affine & $-\log p(x)$  & \textbf{0.985~$\pm$~0.012} & 0.964~$\pm$~0.023 \\

\end{tabular}

The spline coupling layers provide a more expressive bijection, and the typicality score (distance from the mode of the data distribution) aims to correct the known pathology of NLL-based scoring: a well-trained flow assigns its highest likelihood to the mode, so anomalies can sometimes receive higher likelihoods than rare normal samples. However, the typicality correction fails to improve per-class performance: macro per-class PR-AUC drops from 0.985 to 0.937, and the variance nearly quadruples (std 0.047). The typicality score improves global binary separation (0.979 vs 0.964) but hurts discrimination between individual fault classes, suggesting the correction over-smooths the fault-class-specific tails. The affine NLL variant provides a better-calibrated per-class ranking and is adopted as the deployed scoring function.

\subsection{Deployed System: Tiered Alarm Characterisation}\label{sec:ad-deployment}

The deployed anomaly detector uses the \textbf{PC-Flow (baseline\_raw) model from fold~4} (validation-selected fold: val macro per-class PR-AUC~=~0.993) with a three-tier ISA-18.2-inspired escalation system. The tiers form a sequential escalation chain (P3~$\to$~P2~$\to$~P1) and are not independent detectors to be averaged.

\begin{itemize}
    \item \textbf{P3 Advisory}: GPD/sensitive threshold ($\text{FPR} \leq 20\%$), high recall, first-line alert.
    \item \textbf{P2 High}: conformal threshold ($\alpha=0.05$), distribution-free FPR~$\leq$~5\% guarantee, high precision.
    \item \textbf{P1 Critical}: one-sided CUSUM \citep{page1954continuous}, sequential accumulation for persistent anomalies; characterised by detection delay and ARL0 rather than per-sample F1.
\end{itemize}

\subsection{Discussion}\label{sec:ad-discussion}

\paragraph{Why PC-Flow wins.}
The normalizing flow's key advantage over all classical competitors is its joint optimisation of representation learning and exact likelihood estimation. OC-SVM, Isolation Forest, and BOCD all operate on \emph{pre-fixed} feature representations; the quality of their anomaly scores is bounded by the quality of those features. PC-Flow, by contrast, learns its own latent manifold of normal PV operation as a byproduct of maximising the log-likelihood; features and scoring are co-optimised. This explains both the performance gap and the profile ablation result: adding more hand-engineered features does not help a model that already learns better representations from the raw signals.

\paragraph{Where all models agree.}
Open-Circuit (cls~3) is easy for all five models: PR-AUC near~1.0 across the board. Short-Circuit (cls~1) and Open-Circuit produce abrupt, large-magnitude deviations that any anomaly detector with a well-calibrated threshold will catch. All models also perform reasonably on Shadowing (cls~4), which dominates the dataset.

\paragraph{Where models struggle.}
Degradation (cls~2) is the hardest fault across the entire Task~A lineup, including for PC-Flow. With only 19 fault episodes, the per-class PR-AUC estimates carry wide error bars. Degradation manifests as a gradual drift rather than an abrupt event, overlapping the normal-operating manifold at low severity, a structural challenge for any one-class detector.

\paragraph{Binary vs per-class PR-AUC.}
The gap between binary and macro per-class PR-AUC (Isolation Forest: 0.974 vs 0.822; BOCD: 0.870 vs 0.401) is not a quirk of this evaluation design: it reflects the dataset's class imbalance. The binary metric is dominated by the 96\% majority class (Shadowing + Normal); per-class PR-AUC equally weights each fault type. For an FDD system intended to discriminate between fault causes, the per-class view is the operationally relevant one.

\paragraph{Model complexity and edge viability.}
PC-Flow (baseline\_raw) has 20\,124 parameters and 7 input features, a 34\,×\ smaller footprint than the rolling variant and competitive with one-class SVM on inference cost. This is a material advantage for the Jetson Nano deployment target described in Section~\ref{ch:deployment}.

\paragraph{Data limitations.}
The minority fault classes (cls~1: 15 episodes, cls~2: 19 episodes, cls~3: 23 episodes) produce wide error bars across all models, and the five-fold k-fold gives only $\sim$3--5 test episodes per class per fold. Reported means should be read with those confidence intervals in mind. The deployment characterisation (Section~\ref{sec:ad-deployment}) provides the most honest single-model estimate, using the full episode support of the val-selected fold.
